# DiviForge v2.8.1 Release Notes

## Nieuw

- Page-cards op `diviforge-pages` tonen nu een snapshot in de grafische header.
- Featured images krijgen prioriteit als snapshot.
- Gepubliceerde pagina's krijgen automatisch een live snapshot via mShots.
- Draft/private pages tonen een nette fallback-header.

Geen nieuwe workflow-functionaliteit; dit is een gerichte UX-deliverable binnen de MVP-roadmap.
