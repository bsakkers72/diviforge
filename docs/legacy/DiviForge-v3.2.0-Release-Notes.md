# DiviForge v3.2.0 Release Notes

## Added

- AI Preview page.
- AI Jobs page.
- Local AI job queue stored in WordPress options.
- Validation score for AI-generated package responses.
- Approve & update page workflow.
- Discard workflow.
- Responsive preview frames for desktop, tablet and phone.
- Diff-style prompt/response review block.

## Changed

- AI Improve now redirects to AI Preview instead of only showing a raw response in AI Studio.
- AI Improve results are stored as jobs with status and validation metadata.
- DiviForge Importer layout conversion is now callable by the AI import workflow.

## Notes

This release is the first safe bridge between direct AI generation and applying AI output to a Divi page.
