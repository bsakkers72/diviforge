# ADR - DiviForge v3.0.0 AI Foundation

## Status
Accepted

## Decision
Roadmap 3.0 is now the guiding roadmap. DiviForge evolves from an import/export workflow into an AI-native Divi development studio.

## Scope
v3.0.0 introduces the foundation only: AI settings, OpenAI connection test, AI Studio workspace, Prompt Builder, AI package validator indicators, and local AI Request History.

## Non-goals
Direct page generation and automatic import of AI responses are intentionally deferred to v3.1.0 and later.
