# DiviForge v3.0.1 Documentation

## Release theme
AI Provider Layer. DiviForge no longer treats OpenAI as the only AI backend. The Settings screen now introduces a provider-independent foundation for OpenAI, Anthropic Claude, Google Gemini, Azure OpenAI, OpenRouter and Ollama.

## Included
- Active provider selection.
- Model presets grouped by provider.
- Provider-specific API key fields.
- Azure endpoint/deployment fields.
- Ollama local endpoint field.
- Connection Test 2.0.
- Usage dashboard.
- Capability matrix.
- Roadmap 3.0 remains fixed; direct generation follows in v3.1.

## Notes
OpenAI, OpenRouter, Anthropic and Ollama have lightweight connection-test support. Google and Azure settings are stored and prepared; expanded live tests and direct generation are planned in v3.1.
