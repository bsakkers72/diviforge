# Legacy documentation

These `DiviForge-v2.2.0` through `v3.3.0` files (Roadmap, ADR, Documentation, Release Notes) describe the previous, pre-rebuild version of the plugin — the feature-rich implementation that lives in `includes/`.

They are kept for historical reference only. They do not reflect the current architecture or its progress.

Current, authoritative documentation:

- `docs/adr/` — architecture decision records for the ongoing `src/` rebuild.
- `docs/architecture/` — current architecture overview.
- `README.md` (repo root) — current Roadmap 3.0 sprint sequence and status.
