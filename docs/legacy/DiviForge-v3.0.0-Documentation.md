## New in v3.0.0

### OpenAI Settings
Settings now includes:
- API key field
- model name
- temperature
- max output tokens
- timeout
- connection test using the OpenAI Responses API

### AI Studio
AI Studio now provides:
- page selector
- prompt templates
- free-text AI instruction field
- fixed context checklist
- AI package validator readiness panel
- AI Request History

### AI Request History
DiviForge logs AI workflow events locally:
- package exports
- settings updates
- OpenAI connection tests

## Current limitation
v3.0.0 prepares the infrastructure. Direct AI generation from within WordPress is planned for v3.1.0.
