# DiviForge v2.4.1 Release Notes

## Added
- Premium page cards with richer package metadata.
- Package thumbnail import from `preview/`, `thumbnail/`, `thumb/` or package images.
- Automatic featured image assignment for imported package previews.
- Package statistics: sections, rows, columns, modules, images and CSS lines.
- Compact/grid view toggle for the Pages screen.
- New `With thumbnail` page filter.
- Enhanced Package Inspector stats.

## Improved
- Pages screen is now more visual and scalable.
- Cards now better communicate package quality and complexity.
- Package metadata is easier to review at a glance.

## Fixed
- Pages without thumbnails now remain visually consistent through generated initials.
