# DiviForge v3.1.0 Release Notes

## Added
- New **Generate with AI** button in AI Studio.
- Direct OpenAI request flow based on the selected page, prompt preset and custom request.
- AI result review panel in AI Studio.
- AI Request History logs successful and failed direct requests.
- Version overview entry for v3.1.0.

## Changed
- AI Studio now describes the direct AI Improve workflow instead of only export/download workflow.
- Foundation readiness language updated from “prepared for v3.1” to direct v3.1 generation.

## Notes
This version intentionally keeps the workflow safe: generated AI output is shown for review first. Automatic preview and import follow in v3.2.
