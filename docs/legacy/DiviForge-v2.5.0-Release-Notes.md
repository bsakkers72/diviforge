# DiviForge v2.5.0 Release Notes

## Nieuw
- Package Inspector uitgebreid tot eerste MVP-versie.
- Readiness score toegevoegd.
- Manifest metadata wordt overzichtelijk getoond.
- Layoutstatistieken toegevoegd: secties, rijen, kolommen, modules.
- CSS-statistieken toegevoegd: aantal CSS-regels en CSS-status.
- Module types worden geteld en weergegeven.
- Assetlijst en waarschuwingen verbeterd.
- Inspector UI vernieuwd met scorecard, statusbadges en duidelijke grids.

## Verbeterd
- Inspectie blijft volledig veilig: er wordt niets geïmporteerd of gewijzigd.
- Betere visuele feedback tijdens inspectie.
- Bestaande package-import blijft ongewijzigd.

## Bekende beperkingen
- Preview vóór import is nog niet inbegrepen.
- Readiness score is bewust eenvoudig gehouden voor de MVP.
