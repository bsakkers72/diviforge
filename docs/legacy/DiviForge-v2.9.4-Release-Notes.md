# DiviForge v2.9.4 Release Notes

## Added
- `semantic-structure.json` for inferred page roles.
- `statistics.json` for high-level export counts and module-type distribution.
- `relations.json` to connect builder nodes, CSS rules, classes and assets.
- Better asset manifest with `used_by` context.
- CSS analysis v2 with media query context and grouped declaration types.

## Improved
- `builder-tree.json` now includes semantic role hints per node.
- `design.json` extracts tokens from both page CSS and Divi shortcode attributes.
- AI request source list now references the new intelligence files.
- Version overview updated with v2.9.4.
