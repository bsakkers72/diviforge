# DiviForge v2.4.3 Documentation

## Sprint
Sprint 4 — UX & Workflow polish.

## Doel
Deze release blijft bewust binnen de oorspronkelijke MVP-roadmap. Er is geen nieuwe hoofdfunctionaliteit toegevoegd. De focus ligt op visuele afwerking, consistentie en een professionelere Components-pagina als voorbereiding op Sprint 5.

## Belangrijkste wijzigingen
- Components-pagina krijgt echte inline SVG/HTML headers per component.
- Componentkaarten hebben consistente hoogte, metadata en duidelijke Coming Soon-status.
- Algemene UI-polish voor cards, buttons, shadows, uploadvelden en hover states.
- Versie bijgewerkt naar 2.4.3.

## Bewust niet meegenomen
- Componenten zijn nog niet importeerbaar.
- Geen favorieten, tagsysteem of component marketplace.
- Geen nieuwe database-tabellen.
- Geen extra roadmap-scope buiten MVP.

## MVP-richting
DiviForge werkt toe naar een eerste stabiele MVP waarin packages kunnen worden geïnspecteerd, geïmporteerd, geüpdatet en beheerd. Component-import blijft gepland voor een latere sprint.
