# DiviForge v3.3.0 Release Notes

## New
- Added **AI Chat** as a new Studio menu item.
- Added per-page AI chat threads.
- Added AI Chat message handler.
- AI Chat uses the active AI provider and existing page Builder Tree/context.
- AI Chat responses can create AI Preview jobs.
- Added chat UI with page selector, message timeline and prompt form.
- Added Version Overview entry for v3.3.0.

## Changed
- Roadmap 3.0 status updated: v3.3.0 AI Chat is now delivered.
- Admin styling extended with AI Chat layout and message bubbles.

## Safety
AI Chat does not directly update pages. Results must still be reviewed in AI Preview and explicitly approved.
