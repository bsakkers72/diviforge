# DiviForge v2.4.3 Release Notes

## Type release
UX polish release.

## Nieuw
- Grafische SVG componentheaders op de Components-pagina.
- Verbeterde component cards met metadata en CTA placeholders.
- Consistentere card, button en upload styling.

## Fixes
- De componentheaders zijn nu daadwerkelijk in PHP/HTML opgenomen, niet alleen als mock-up of losse CSS-variant.

## Installatie
Upload `diviforge-v2.4.3-plugin.zip` via WordPress > Plugins > Nieuwe plugin > Plugin uploaden.
