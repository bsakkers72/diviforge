# DiviForge v2.4.0 Release Notes

## Main improvement

Sprint 4 begins with a new Studio-style UX for DiviForge.

## Added

- New Studio dashboard
- New Pages screen with page cards
- Existing Import Package URL now opens the Pages workflow
- Package Library shell
- Templates shell
- Modern Studio navigation
- Search on page cards
- Filters for All, Published, Draft and DiviForge pages
- Better quick-create form
- Recent imports panel
- Sprint 4 roadmap strip

## Preserved

- Existing package import engine
- Existing CSS import to Divi Page Custom CSS
- Existing preview, Divi, edit, CSS and delete actions

## Next

v2.4.1 should add package thumbnails, tags and favorites.
