# DiviForge v2.6.0 Release Notes

## Added
- Package Preview inside the Package Inspector.
- Desktop / Tablet / Mobile preview toggles.
- Lightweight iframe preview generated from package layout data.
- Preview CSS loading from `page.css`.

## Changed
- Plugin version bumped to 2.6.0.
- Inspector language updated from Sprint 5 to Sprint 6.

## Known limitation
The preview is an approximation, not a full Divi render. The final result should still be checked using the page preview after import.
