# DiviForge v2.6.0 Documentation

## Sprint 6 — Package Preview MVP

This release continues the original MVP roadmap. It adds a lightweight visual preview to the existing Package Inspector.

### Included
- Inspect `.zip` / `.dfg` packages before import.
- Show metadata, readiness score, required files, package stats and warnings.
- Generate a lightweight visual preview from `layout.json`.
- Apply `page.css` inside the preview iframe where possible.
- Toggle preview width between Desktop, Tablet and Mobile.
- Keep import flow unchanged: create/update pages from the Pages screen.

### Not included yet
- True Divi frontend rendering before import.
- Persisted temporary package uploads.
- One-click import directly from Inspector.
- Package history / rollback.

## MVP focus
This version intentionally avoids new scope beyond preview. The goal is to help users make a safer import decision before creating or updating a page.
