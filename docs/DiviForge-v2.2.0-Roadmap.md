# DiviForge Roadmap after v2.2.0

## v2.3 - Asset Import

- Upload package images to WordPress Media Library.
- Replace package-local image paths with real media URLs.
- Add asset registry metadata.
- Add warnings for missing or unused assets.

## v2.4 - Layout Importer Expansion

- Better support for Divi row structures.
- Preserve section, row, column and module classes.
- Support additional modules: blurb, divider, code, testimonial, pricing and FAQ patterns.
- Improve shortcode generation and escaping.

## v2.5 - Package Versioning

- Store package history per page.
- Re-import CSS only.
- Re-import layout only.
- Compare package versions.
- Rollback to previous import.

## v3.0 - DiviForge Studio

- Prompt Studio.
- Package Studio.
- Preview engine for desktop/tablet/mobile.
- Component library.
- Design system support.
- Marketplace-ready package structure.
