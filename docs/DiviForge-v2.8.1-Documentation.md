# DiviForge v2.8.1 Documentation

## Page snapshots op Pages

De Pages-pagina toont vanaf deze versie in de grafische header van iedere page-card een visuele snapshot van de betreffende pagina.

Prioriteit:

1. Featured image van de pagina.
2. Live page snapshot via WordPress.com mShots voor gepubliceerde pagina's.
3. Premium fallback-header voor concepten en private pagina's.

Deze wijziging is bewust klein gehouden en past binnen de MVP-roadmap als UX-verbetering op de bestaande Pages-weergave.
